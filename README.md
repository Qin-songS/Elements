# 知识大厦 · 第一版原型

这是一个不依赖外部前端库的本地交互原型，用来验证“定义／公设／共同观念 → 命题”的知识依赖模型，以及问题驱动的亲手建造流程。

## 打开方式

在本目录启动任意静态文件服务器，例如：

```powershell
python -m http.server 4173
```

然后访问 `http://localhost:4173`。

## 目前可以体验

- 在顶部切换“观察”和“建造”两种模式。
- 从下到上浏览《几何原本》第一卷的演示性依赖剖面。
- 点击节点，在右侧查看陈述、直接前提、推导摘要和结构影响。
- 关闭共同观念或作图公设，观察上层命题如何连锁失去支持。
- 按知识类型筛选节点，搜索命题，拖动画布并缩放。
- 在第一关中阅读目标后，完全在纸上或脑海中完成等边三角形构造。
- 按需逐级展开三层提示，不要求在电脑中输入、画图或提交答案。
- 用三个关键问题自检，再按需展开参考构造与完整证明。
- 记录“独立完成／提示后完成／需要重做／暂未理解”，理解确认后再安放命题。
- 在窄屏上使用抽屉式筛选和节点详情。

## 文件边界

- `knowledge/manifest.json`：当前原型的知识源头。
- `app.js`：依赖计算、交互和视图状态。
- `build-mode.js`：第一关的几何工具、提示、验收和解锁状态。
- `styles.css`：视觉系统及响应式布局。
- `index.html`：应用界面骨架。

当前数据明确标记为“演示性依赖模型”，不是对《几何原本》原文的完整形式化。后续可以把一个节点一个文件的 Markdown/YAML 数据源加入生成流程，而不用改动可视化层的语义。
