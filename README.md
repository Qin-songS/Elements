# 知识大厦 · 全局骨架原型

这是一个不依赖外部前端库的本地交互原型。它用“楼层导航 + 依赖网络”表现知识如何从元规则、逻辑和集合出发，进入数的构造、通用结构、主要理论与跨域应用；学习者则通过离线挑战亲手安放每一块地基。

## 打开方式

在线访问：<https://songs061207-pixel.github.io/Elements/>

在手机浏览器中打开后，可从左侧菜单选择“添加到手机桌面”。支持安装的浏览器会显示原生安装界面；其他浏览器可从浏览器菜单使用“添加到主屏幕”。完成首次加载后，应用外壳与两份知识数据可离线使用。

如需在本地开发，可在本目录启动任意静态文件服务器，例如：

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

然后访问 `http://localhost:4173`。

## 目前可以体验

- 在顶部切换“观察”和“建造”两种模式。
- 从第 −1 层向上浏览 37 个全局路线节点和 87 条暂定依赖。
- 在“整座大厦”和“几何翼”之间切换；旧版《几何原本》依赖原型完整保留。
- 点击节点，在右侧查看陈述、直接前提、推导摘要和结构影响。
- 关闭元规则、集合公理或几何公设，观察上层区域如何连锁失去支持。
- 按知识类型筛选节点，搜索命题，拖动画布并缩放。
- 在第 −1 层第一关中，完全在纸上或脑海中判断哪些表达式具有真值。
- 按需逐级展开三层提示，不要求在电脑中输入、画图或提交答案。
- 用三个关键问题自检，再按需展开参考分类与完整理由。
- 记录“独立完成／提示后完成／需要重做／暂未理解”，理解确认后再安放地基并解锁“真值与否定”。
- 在手机上使用可关闭的路线抽屉、移动搜索和底部节点详情。
- 单指移动图谱、双指缩放，并用双击重新定位当前节点。
- 自动把 M.1 挑战进度保存在当前设备，刷新或重新打开后继续。
- 安装到手机桌面，并在首次联网加载后离线访问。

## 文件边界

- `knowledge/edifice.json`：整座知识大厦的全局骨架与暂定依赖。
- `knowledge/manifest.json`：保留的欧氏几何翼原型。
- `app.js`：两种观察范围的加载、依赖计算、搜索和视图状态。
- `build-mode.js`：第 −1 层第一关的提示、自检、核对和解锁状态。
- `manifest.webmanifest`：手机安装信息、主题与应用图标声明。
- `service-worker.js`：应用外壳与知识数据的离线缓存。
- `icons/`：PWA 与手机桌面使用的黑金应用图标。
- `styles.css`：视觉系统及响应式布局。
- `index.html`：应用界面骨架。

全局数据是课程建筑图，不声称给出了数学基础的唯一正确顺序；几何数据也仍是演示性依赖模型，而不是对《几何原本》原文的完整形式化。后续可把每个节点拆成独立 Markdown/YAML 数据源，而不改变可视化层的语义。
